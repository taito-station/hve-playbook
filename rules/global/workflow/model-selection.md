# モデル使い分け規約

実装作業は基本的に `impl-sonnet` subagent（Sonnet）に委譲し、コスト効率を優先する。
以下のいずれかに該当する場合はメインループ自身（Opus）が対応する。

- 影響範囲が広い（複数ファイル・複数モジュールにまたがる変更、既存アーキテクチャへの影響がある）
- 原因不明のバグ調査
- 設計・意思決定を伴う実装

委譲するかどうかは着手前に都度判断する。判断に迷う場合は委譲せず自分（メインループ）で対応する。

`impl-sonnet` から「影響範囲が広い」「原因不明のバグ」「方針選択が必要」と報告が返った場合は、
そこで委譲を打ち切りメインループ側で引き取る。
